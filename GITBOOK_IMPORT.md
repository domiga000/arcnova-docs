# How to Use This Package

1. Upload this folder to a GitHub repository.
2. In GitBook, create a new space.
3. Choose **Synchronize with GitHub**.
4. Select the repository and use this folder as the docs root.
5. GitBook will use `SUMMARY.md` to build the sidebar navigation.

Note: The original Google Docs image placeholders were removed because the exported Markdown did not include actual image assets. Add images manually later if needed.
