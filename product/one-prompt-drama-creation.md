# One-Prompt Drama Creation

One-prompt drama creation is one of ArcNova’s core product concepts.

Creators can start with a simple idea, prompt, or story direction, and ArcNova helps expand it into a more complete cinematic workflow.

A prompt may become:

* A story concept
* A character setup
* A script outline
* A scene structure
* Dialogue
* Visual direction
* Short-form video content

The goal is to make the creative process more accessible.

A user does not need to begin with a full script, production crew, or technical workflow. They can start with an idea and gradually turn it into content.
